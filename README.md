# AutoZ — русская версия

Русский форк [etng/autoz](https://github.com/etng/autoz). AutoZ показывает время выбранного часового пояса в строке меню macOS и может менять **системный часовой пояс по внешнему IP**. Требуется macOS 13 или новее.

Переведены меню, настройки, уведомления, ошибки, диагностика, справка CLI и сообщения помощника. Даты и названия поясов в меню и настройках используют `ru_RU`. Формат часов в самой строке меню сохраняет язык системы и настройку 12/24 часов. Идентификатор приложения и ключи настроек сохранены для совместимости с оригиналом.

При VPN или прокси определяется местоположение выходного сервера. Синхронизация отключает автоматический выбор часового пояса macOS. Домашний пояс по умолчанию остаётся `Asia/Shanghai`, как в оригинале; другой пояс можно выбрать в настройках.

## Сборка и запуск

Нужны Xcode Command Line Tools (`xcode-select --install`). Сторонние зависимости не требуются.

```bash
git clone https://github.com/Mihaliks/autoz.git
cd autoz
./build.sh
open dist/AutoZ.app
```

`./build.sh --run` собирает и запускает именно локальную сборку. Для универсальной сборки:

```bash
AUTOZ_ARCHS="arm64 x86_64" ./build.sh
```

Во время сборки выполняются 11 проверок протокола и безопасности помощника, а также проверки часовых поясов и русской локализации. Они не меняют системный часовой пояс. Приложение подписывается локальной ad-hoc подписью; Apple Developer ID и нотариального заверения нет.

## Замена версии Homebrew

Сначала соберите и проверьте приложение. Если оригинал запущен, завершите его через меню. Сохраните резервную копию `/Applications/AutoZ.app`, если нужен откат. Затем:

```bash
brew uninstall --cask autoz
# Убедитесь, что /Applications/AutoZ.app больше не существует.
# Если там осталась другая копия, сначала проверьте и сохраните её.
cp -R dist/AutoZ.app /Applications/AutoZ.app
open /Applications/AutoZ.app
```

Удаление без `--zap` сохраняет настройки и LaunchAgent. Путь приложения остаётся тем же, поэтому существующий автозапуск продолжает указывать на установленную версию. Homebrew больше не обновляет эту копию.

## Управление

Нажмите часы в строке меню. Сверху показаны выбранный пояс часов, системный пояс с местным временем и результат последней проверки внешнего IP. Оранжевые часы означают отличие выбранного времени от системного.

| Пункт | Действие |
|---|---|
| Включить синхронизацию по IP | Следить за сетью и менять системный пояс по внешнему IP |
| Проверить и синхронизировать один раз | Однократно определить и применить пояс, не меняя переключатель синхронизации |
| Вернуть домашний пояс | Вернуть заданный пояс и отключить синхронизацию |
| Часовой пояс часов… | Выбрать часовой пояс для часов в строке меню |
| Настройки… | Открыть шесть разделов настроек |
| Завершить AutoZ | Закрыть приложение; при включённых синхронизации и автовозврате вернуть домашний пояс, если помощник готов |

Пояс часов выбирается через **Часовой пояс часов…** в меню или **Настройки → Строка меню → Пояс часов → Изменить…**. Например, `Europe/Istanbul` — турецкое время. Выбор применяется сразу и сохраняется после перезапуска; он не меняет системный или домашний пояс. До первого выбора часы сохраняют прежний пояс `Asia/Shanghai`.

В настройках также доступны синхронизация и домашний пояс, секунды в строке меню, автозапуск, авторизация, журнал и диагностика. В выборе домашнего пояса вводите идентификатор IANA (`Europe/Moscow`) или часть названия (`moscow`). Неоднозначный запрос не применяется.

Автосинхронизация проверяет сеть через 15 секунд после изменения подключения и дополнительно каждые 10 минут. Без помощника фоновая проверка только сообщает о смене пояса; применить его можно вручную с авторизацией администратора.

## Помощник и авторизация

**Настройки → Авторизация → Установить помощника**: один запрос пароля администратора, затем смена пояса без повторных запросов. Альтернативы — Security.framework или AppleScript с авторизацией для каждой операции.

Помощник запускается через launchd по запросу и выходит после 20 секунд бездействия. Он принимает только `ping`, `state`, `set_zone`, `set_auto`, проверяет UID клиента и допустимость пояса, затем перепроверяет `/etc/localtime`. Произвольные команды не поддерживаются.

Файлы помощника:

- `/Library/LaunchDaemons/cn.y10n.autoz.helper.plist`
- `/usr/local/libexec/autoz-helper`
- `/var/run/cn.y10n.autoz.sock`

Удаление: **Настройки → Авторизация → Удалить помощника**. Оно требует авторизации администратора и удаляет только эти три пути.

## Командная строка

```bash
./autoz.sh help               # Все команды
./autoz.sh check              # Только проверить IP и пояс
./autoz.sh system             # Текущий системный пояс
./autoz.sh menu               # Меню в текстовом виде
./autoz.sh plan Europe/Moscow # План смены пояса без выполнения
./autoz.sh helper-status      # Состояние помощника
./autoz.sh helper-selftest    # 11 проверок без изменения системы
./autoz.sh tz-selftest        # Часовые пояса и русская локализация
```

`autoz.sh` использует бинарник из `dist/AutoZ.app`. Для установленной копии те же флаги доступны через `/Applications/AutoZ.app/Contents/MacOS/AutoZ --help`.

## Диагностика

- Журнал: `~/Library/Logs/AutoZ.log`.
- Журнал помощника: `/var/log/cn.y10n.autoz.helper.log`.
- Настройки: `~/Library/Preferences/cn.y10n.autoz.plist`.
- Автозапуск: `~/Library/LaunchAgents/cn.y10n.autoz.plist`; применяется при следующем входе в систему.
- Если пояс не меняется, проверьте результат определения IP и состояние помощника в разделе «Авторизация».
- Если помощник установлен, но не отвечает, переустановите его через настройки.
- Если часы не видны, освободите место в строке меню.

Для ручного восстановления московского пояса и автовыбора macOS:

```bash
sudo systemsetup -settimezone Europe/Moscow
sudo defaults write /Library/Preferences/com.apple.timezone.auto Active -bool true
```
